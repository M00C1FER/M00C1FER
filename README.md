## Two repos worth your time first

**[`mcp-citation-research`](https://github.com/M00C1FER/mcp-citation-research)**
MCP server that hard-mandates research quality: 4-axis source floor (domain count,
page count, iteration depth, confidence gate ≥0.90), BM25 citation injection, and
CRAAP scoring. Rejects synthesis below threshold rather than producing confident noise.

**[`memory-tool-conformance`](https://github.com/M00C1FER/memory-tool-conformance)**
Defines a 6-operation contract for LLM memory tools and provides a conformance test
suite against it. No existing framework I found does this — most just assume memory
tools work.
